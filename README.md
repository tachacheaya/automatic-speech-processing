## Automatic Speech Processing — From Signal Acquisition to Neural Architectures

## 📌 Overview

This project presents an introduction to Automatic Speech Processing (ASP), from speech signal acquisition and classical signal analysis to modern neural architectures.

The project combines theoretical concepts with Python-based experiments for analyzing and processing speech signals.

## 🎯 Objectives

The main objectives of this project are:

- Analyze speech signals in the time and frequency domains.
- Study the acoustic characteristics of speech.
- Apply FFT and spectrogram analysis.
- Extract Mel-Frequency Cepstral Coefficients (MFCCs).
- Estimate pitch using PYIN.
- Extract formants using Linear Predictive Coding (LPC).
- Explore major applications of Automatic Speech Processing.
- Introduce modern Transformer-based architectures and wav2vec 2.0.

## 🛠️ Technologies and Libraries

- Python
- NumPy
- SciPy
- Librosa
- Matplotlib
- SpeechRecognition

## 🔬 Main Topics

### 1. Speech Signal Analysis
Study of speech signals in the time and frequency domains.

### 2. FFT and Spectrogram
Frequency analysis and visual representation of speech signals.

### 3. MFCC
Extraction of Mel-Frequency Cepstral Coefficients for speech analysis and recognition.

### 4. Pitch Estimation
Pitch estimation using the PYIN algorithm and comparison of speech characteristics.

### 5. Formant Analysis
Formant extraction using Linear Predictive Coding (LPC).

### 6. Speech Processing Applications

The project discusses applications such as:

- Automatic Speech Recognition (ASR)
- Text-to-Speech (TTS)
- Speaker Recognition
- Speech Coding and Compression
- Speech Enhancement

### 7. Modern Neural Architectures

The project also introduces modern approaches based on:

- Transformers
- wav2vec 2.0

## 📊 Results

The project includes visual analyses of speech signals, spectrograms, MFCCs, pitch estimation, and formant extraction.
